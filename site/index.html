What it does

  • Chats

    Every bot has its own job, model and conversation. Queue messages while it works.

  • Access

    A new bot asks before it acts outside its own folder. You decide how far each one may go.

  • Rounds

    Work that runs on a schedule, with the next 7 days in view.

  • Rooms

    Put a question to a team, and its lead decides who helps.

  • Optimizer

    Smaller conversations, and a count of the tokens saved.

  • Logbook

    What was done, by whom, and how it ended.

Also a browser for bots, a Keyring for logins on one exact website each, and English or Bahasa Indonesia. The full list

Everything stays on your computer.

There is no Markas account, cloud service or telemetry. Your bots still reach the services their engines use, such as Anthropic and OpenAI, or the model services you set up in OpenCode.

Install

Windows

The installer from the latest release. If Windows says it protected your PC, choose More info, then Run anyway.

macOS

The disk image for Apple silicon or Intel. If macOS could not verify it, choose Open Anyway in System Settings, Privacy & Security. Or the command line:

brew tap avelixio/markas https://github.com/avelixio/markas
brew install avelixio/markas/markas

Linux

The AppImage, or the install script, which checks the download against the release's SHA-256 list:

curl -fsSL https://raw.githubusercontent.com/avelixio/markas/main/install.sh | sh

Bots need Claude Code, Codex or OpenCode. Markas finds them, and can install and connect them for you.

Markas is an early preview. A new bot asks before it acts outside its own folder, but a bot you give full access can change and delete files on your computer. Run only bots and tasks you trust.
