# Markas glossary

Markas means headquarters, and its parts are named after a headquarters.
Use these names in the interface, the docs and the code.
Each name must still be clear to someone who has never seen the app, so every one is paired with a plain one-line meaning that the interface shows on first use.

| Name | Plain meaning | Notes |
| --- | --- | --- |
| Bot | An AI teammate with its own job | Never "agent" in the interface |
| Crew | All your bots together | The sidebar list |
| Sigil | A bot's badge: a pattern and a colour | Square tiles are bots, round monograms are people |
| Quarters | A bot's own folder | Instructions, notes and working files |
| Dispatch | The bot that sets up other bots and passes work on | Part of Markas, not one of your bots. In the middle of the screen until the first bot exists, then pinned at the top |
| Ready-made bot | A bot someone already built, ready to add and change | Each is one bot file |
| Bot file | One file that describes a bot, so it can be shared and imported | |
| Keyring | Logins and secrets bots can use but never read | Each key has its own name and one exact website |
| Key | One saved login, token or variable | |
| Rounds | Work a bot does on a schedule | One round is one scheduled job |
| Checkpoint | Where an action that matters stops for your OK | |
| Logbook | The permanent record of what bots did | |
| Switchboard | The outside services and sign-ins Markas keeps alive | |
| Archive | Every file you gave or a bot made | |
| Fuel | How much of each engine's plan is left | |
| Signal | The small always-on-top strip that tells you something needs you | |
| Beacon | The signal folded down to one tile | Its colour is the state of the crew |
| Hand-off | A bot passing a step to you that only you can do | A phone code or a CAPTCHA |
| Engine | The tool a bot runs on, such as Claude Code or Codex | |
| Waiting on you | A bot is stopped until you answer, approve or sign in | Always amber |

## Rules

- A themed name is used for a place or a thing, never for a button.
Buttons say what they do: Save, Send, Approve.
- Statuses stay plain: Working, Waiting on you, Failed, Held.
- If a themed name ever makes a sentence harder to understand, use the plain meaning.
