## Fixed in this run

1. **Grants after a level change (security).** A yes "for this chat" lived on inside the Claude and OpenCode clients when the person raised a bot to Full access and lowered it again between two turns, so the bot read new files outside its folder without asking. Markas now tells the engine to drop those answers at the bot's next turn (`forgetChatGrants`).
2. **Engine startup race.** Right after the host started, setup could show Claude Code as "could not finish checking", and a second Claude client could be started beside the first. Engine starts are now shared, and a question about an engine waits for its start to finish.
3. **macOS edit shortcuts in the desktop app.** The menu was removed on every system, which on macOS also removes Cmd+C, Cmd+V, Cmd+Z, Cmd+A and Cmd+Q. macOS now keeps the app, Edit and Window menus.
4. **macOS backup clutter.** The data backup held a hidden `._markas-data.json`. `ditto` now leaves out extended attributes.
5. **Empty bot folder after removal for good.** The bot's own empty folder is now removed. A folder the person chose, or one that still holds files, stays.

## Found, not fixed

- Dispatch, ready-made bots and bot-file import can only be reached during first-run setup.
- English text in the Indonesian UI (scenario 10).
- Chat replies show Markdown as raw text (`**bold**`, backticks).
- A cancelled queued message appears below a message sent after it.
- `scripts/e2e-ui.mjs` expects the main screen straight away and stops at the language step.
- The data backup calls `/usr/bin/ditto` on every system that is not Windows, so it cannot work on Linux.
